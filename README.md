# Miron — портфолио разработчика

Создаю веб-приложения и автоматизации: Telegram-боты, интеграции API, адаптивные интерфейсы и локальные инструменты для бизнеса.

## Публичные проекты

- [Telegram Mini App и бот-портфолио](https://github.com/cardistrytop179-alt/portfolio-ecosystem) — React-интерфейс, Telegram Web App, API на Express, проверка подписи `initData` и база PostgreSQL/Prisma.
- [Бот уведомлений о драфтах Dota 2](https://github.com/cardistrytop179-alt/dota-draft-bot) — независимый опрос STRATZ и Steam, сохранение очереди перед отправкой и восстановление после перезапуска.
- [Showcase Portfolio Bot](https://github.com/cardistrytop179-alt/showcase-bot) — демонстрационный Telegram-бот с пошаговой формой, напоминаниями и API курсов криптовалют.
- [Clearpath Astro Demo](https://github.com/cardistrytop179-alt/clearpath-demo) — двуязычная демонстрационная страница на Astro и TypeScript.
